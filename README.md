# CloudBackup – Secure Cloud Backup and Disaster Recovery System Using AWS

## 📌 Project Overview
CloudBackup is a secure, automated, and scalable cloud-based backup and disaster recovery system developed using Amazon Web Services (AWS). It protects important data through encrypted backups, versioning, cross-region replication, and quick data recovery.

## ✨ Key Features
- Automated scheduled backups
- Secure data encryption using AWS KMS
- Backup storage using Amazon S3
- Versioning and retention policies
- Cross-region replication
- Disaster recovery and data restoration
- Monitoring and notifications

## 🛠️ AWS Services Used
- Amazon S3 and S3 Glacier
- AWS Backup
- Amazon EC2, EBS and RDS
- AWS IAM
- AWS KMS
- AWS Lambda and EventBridge
- CloudWatch, CloudTrail and SNS
- AWS Elastic Disaster Recovery

## 🎯 Project Objective
To provide reliable data protection, reduce data loss, improve recovery speed, and ensure business continuity.
